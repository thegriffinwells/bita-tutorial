What is Claude Code?

Claude Code is like having a really smart friend who knows how to code. You tell it what you want in normal words, and it does the coding part for you. It can read your whole project, make changes, and even save your work.

💻

In Your Terminal

That black window where developers type things. You just type claude and start talking to it.

🖥

Desktop App

A regular app you can download on your Mac or PC. Click to open, just like anything else.

🌐

In Your Browser

Go to claude.ai/code and use it right there. Nothing to download.

Think of it as a patient, friendly coding partner who never gets tired, never judges your questions, and is happy to explain everything.

Getting Started

Five simple steps. You've got this, Bita.

1

Get an Account

You need a Claude Pro or Max subscription. It's like a Netflix plan but for your AI coding buddy. Or, skip everything and just go to claude.ai/code in your browser — no downloads needed.

2

Download It

Open your terminal (the black window on your computer) and paste one of these lines depending on what kind of computer you have:

brew install claude-code
winget install Anthropic.ClaudeCode
npm install -g @anthropic-ai/claude-code

Just copy the line, paste it in your terminal, and hit Enter. It installs itself and stays up to date automatically.

3

Open It

Go to a project folder (any folder with code in it) and type claude:

$ cd my-project
$ claude

That's literally it. Claude will look around your project and introduce itself.

4

Ask It Something

Just type what you want, like you're texting a friend. Here are some ideas:

"What does this project do? Explain it simply"
"Make me a webpage with a pink header and a photo gallery"
"Something is broken, can you find and fix it?"
"Add a contact form to my website"
5

Pick How Much Freedom to Give It

You choose how much Claude can do on its own. Start with Edit mode so it always asks before changing anything.

Ask

Claude can only answer questions. It can't change anything. Good for exploring.

Edit Start Here

Claude can make changes, but it'll ask you "is this okay?" every time first.

Auto

Claude just goes for it. Great once you trust it and want to move fast.

That's it, Bita! You're officially a Claude Code user now!

Good to Know

You don't need to memorize these. Just nice to know they exist. Tap to learn more.

This is a little note you can leave in your project folder that tells Claude how you like things done. It's like leaving a sticky note for a house sitter: "always take shoes off at the door." For example, you could write "always use bright colors" or "keep the code simple." Claude reads it every time it starts.

These are little shortcuts that start with a / symbol. Type /help to see what Claude can do, or /bug to report a problem. Think of them like keyboard shortcuts — totally optional, but handy once you know them.

This is how Claude talks to other apps you use, like GitHub (where code lives online) or Slack. You don't need to set this up right away — just know that Claude can eventually connect to your other tools when you're ready.

Sometimes you want Claude to explain what it's going to do before it actually does it. Plan Mode is like saying "hey, tell me your plan first." You turn it on by pressing Shift+Tab twice. Really useful for bigger projects where you want to review the game plan.

When Claude has a really big task, it can create little helper versions of itself to work on different parts at the same time. Imagine asking one friend to help you move, and they show up with three more friends. That's subagents.

Tips & Tricks

Give details. "Make the header pink with rounded corners" works way better than "make it look nice." The more you describe, the closer Claude gets to what's in your head.

Ask it to plan first. Press Shift+Tab twice and Claude will tell you its plan before doing anything. Great for big stuff.

Leave Claude a note. Create a file called CLAUDE.md in your project with your preferences. Claude reads it every time, like a little cheat sheet.

No install? No problem. Just go to claude.ai/code in your browser. Everything works right there.

You can't break anything. Seriously. Claude asks before making changes (in Edit mode), and you can always undo. So experiment freely!

Type /help if you're lost. This shows you everything Claude can do. It's like a built-in instruction manual.
