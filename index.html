What is Claude Code?

Claude Code is a tool by Anthropic that understands your codebase, edits files, runs commands, and handles git workflows — all through natural language. You just tell it what you want in plain English.

💻

Terminal CLI

Run claude in your terminal for the full power-user experience.

🖥

Desktop App

A standalone app that works with your projects on macOS and Windows.

🌐

Browser

Use it at claude.ai/code with zero local setup.

Think of it as a senior developer in your terminal who never gets tired, never judges your questions, and always explains their work.

Getting Started

Follow these steps and you'll be up and running before you know it.

1

Get Access

Sign up for a Claude Pro or Max subscription, or use API credits via the Anthropic Console. The browser version at claude.ai/code requires no local install at all.

2

Install Claude Code

Pick the method that matches your system:

brew install claude-code
winget install Anthropic.ClaudeCode
npm install -g @anthropic-ai/claude-code

Native installs (brew & winget) auto-update. The npm method works on any OS.

3

Launch It

Navigate to any project folder and type:

$ cd my-project
$ claude

That's it. Claude will scan your project and say hello.

4

Try Your First Prompt

Here are some great things to try first:

"Explain what this codebase does"
"Create a simple HTML page with a nav bar"
"Find and fix any bugs in app.js"
"Write tests for the login function"
5

Learn the Modes

Claude Code has three modes. We recommend starting in Edit mode.

Ask

Read-only. Great for questions. Claude looks but doesn't touch.

Edit Recommended

Claude can modify files, but asks your permission first.

Auto-accept

Claude runs freely. Best once you're comfortable and trust the workflow.

Key Concepts

A quick glossary of things you'll encounter. Click to expand.

A special file you put in your project folder that tells Claude your rules and coding standards. Think of it as a style guide for your AI pair programmer. For example, you can tell Claude to always use TypeScript, prefer functional components, or follow a specific naming convention.

Shortcuts that start with / that trigger specific actions. For example, /bug reports issues, /help shows available commands, and your team can create custom ones. They're like keyboard shortcuts but for Claude.

The way Claude connects to external tools like GitHub, Slack, and databases. MCP lets Claude reach beyond your local files to interact with the services your project depends on. Think of it as giving Claude permission to use your other tools.

A special mode (activated by pressing Shift+Tab twice) that forces Claude to think and plan before writing any code. Great for complex tasks where you want to review the approach before Claude starts making changes.

Specialized Claude instances that handle complex tasks in parallel. When Claude faces a big job, it can spin up subagents to work on different parts simultaneously — like having a small team instead of one developer.

Tips & Tricks

Be specific. The more context you give, the better the results. "Fix the login bug where users can't reset passwords" beats "fix the bug".

Use Plan Mode first. Press Shift+Tab twice before big tasks so Claude thinks before it acts.

Create a CLAUDE.md file. Teach Claude your project's rules and preferences. It reads this file every session.

Try the browser version. Go to claude.ai/code if you don't want to install anything at all.

Pipe things in. From your terminal, try git diff | claude "review this" to send output directly to Claude.

Type /help anytime. If you're ever stuck, this command shows you everything Claude can do.
